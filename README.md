# Business English Studio

Interactive web application for learning Business & Academic English (B2 level), built with **React, TypeScript, Vite, and Tailwind CSS**.

## Features

- **Units 1–5 Review Hub** — Structured practice for *Organisation*, *Brands*, *Job Hunting*, *Business Strategy*, and *Logistics* with instant feedback and explanations.
- **Spaced Repetition Flashcards (SRS)** — 100+ flashcards with audio pronunciation (Web Speech API), keyboard shortcuts (`Space` to flip, `1/2/3` to rate), unit filters, and a dedicated filter for tricky/uncommon vocabulary from business articles & videos.
- **Word Formation Trainer** — Interactive fill-in-the-table quizzes (*Verb / Noun / Adjective / Adverb*), 30 exam-style sentence drills with random 10-question tests, 45 word families, and a suffix/prefix cheat sheet.
- **Grammar Reference & Drills** — Concise rules and interactive exercises covering Modal Verbs, Comparison, Passive Voice, Contrast Linking (*despite* vs *although*), Future Forms, Gerund vs Infinitive, Indirect Questions, Time Clauses (*until, as soon as, unless*), Conditionals (0–III), *I wish / I’d rather*, *should have*, and Mixed Tenses.
- **Functional Language Bank** — Searchable business phrases with register tags (`formal`, `neutral`, `informal`), audio playback, and dialogue quizzes.
- **Writing Studio** — Guided editor with live word counter (`180–200` word exam target), auto-saved drafts, interactive checklists, clickable phrase banks, and model answers (Reports, PEST Analysis, Formal Complaints, Diplomatic Emails, Letters of Apology).
- **Mock Exam Simulator** — Full interactive practice exams (Reading True/False, Synonyms, Gapped Text, Multiple Choice, Word Formation, Open Cloze, and Grammar) with countdown timer and explanations.
- **Local Progress & JSON Backup** — All SRS progress, quiz scores, and writing drafts are stored in `localStorage` with one-click JSON export/import.

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
